# E-gertonLMS

An institutional Learning Management System (LMS) prototype built for academic course management. **E-gertonLMS** provides an interactive web interface allowing academic staff and students to manage course catalogs in real time, with seamless data persistence.

## Tech Stack

### Frontend
* **React** (with **Vite**)
* **Tailwind CSS**

### Backend
* **FastAPI** (Python)
* **SQLModel**
* **Google OAuth 2.0**

### Database & Infrastructure
* **Supabase** (PostgreSQL)
